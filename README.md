<h1>Movie-Recommender-System</h1>
A Content-Based Movie Recommender System that suggests similar movies based on a user's selection. This project uses natural language processing (NLP) techniques to compute movie similarity based on overviews, genres, keywords, cast, and crew.

<h1>Features</h1>
Content-Based Filtering: Recommends movies by finding the ones most similar to a selected movie's features.

Dynamic Recommendations: Suggests top 5 movies similar to the user's choice.

Interactive Web Interface: Built with Streamlit for a user-friendly and responsive experience.

Movie Posters: Displays movie posters fetched from The Movie Database (TMDb) API to make the interface more engaging.

Pre-computed Similarity: Uses a pre-calculated similarity matrix for fast and efficient recommendations.

<h1>Tech Stack</h1>
Data Processing: Pandas, NumPy

Machine Learning/NLP: Scikit-learn (for CountVectorizer and cosine_similarity)

Web Framework: Streamlit

API Integration: Requests (for TMDb API)

Programming Language: Python
